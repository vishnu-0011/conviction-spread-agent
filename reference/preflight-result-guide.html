Both conditions are required before moving toward any order-path validation.

Control plane

  • paper_authentication: keys reach the paper host.
  • account_active: brokerage status is operational.
  • account_unblocked: account and trading flags are clear.
  • options_level_3: atomic spreads are permitted.
  • options_buying_power: positive paper capacity exists.

Data plane

  • market_clock: decisions can use broker session time.
  • underlying_snapshot: spot-relative strikes can be selected.
  • option_contract_discovery: active contract metadata exists.
  • indicative_option_snapshots: selected contracts have market data.
  • greeks_and_iv_observed: analytics exist but remain nullable.

Common interpretation mistakes

Contract exists ≠ quote exists. Contract metadata can be active and tradable even when the selected contract has no usable latest Indicative snapshot.
Greeks missing ≠ subscription broken. Alpaca also requires non-zero bid/ask, an underlying SIP trade, time to expiry, and a convergent implied-volatility calculation.
Lesson: debug an empty option-snapshot result. Primary sources: Snapshots and Option chain.
