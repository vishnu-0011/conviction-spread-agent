Alpaca paper-key checklist

Dashboard

  • Sign in at app.alpaca.markets.
  • Confirm email and activate MFA if this is a new account.
  • Use the upper-left account selector and choose Paper Trading.
  • Open the Home/API section and locate the API Keys panel.
  • Select Generate New Key or Generate API Keys.
  • Copy both values immediately; the secret is shown only once.

Local file

Copy-Item .env.example .env
# Open .env in your editor and replace only the two empty values.
ALPACA_API_KEY=PASTE_KEY_ID_HERE
ALPACA_SECRET_KEY=PASTE_SECRET_HERE
ALPACA_PAPER=true
CSA_EXECUTION_ENABLED=false
CSA_DRY_RUN=true

Safety checks

git check-ignore .env
python scripts/preflight.py --underlying SPY `
  --output data/private/preflight.json
Never: paste credentials into chat, commit .env, use live keys, include keys in screenshots, or regenerate them without updating every local integration.
