# Teaching notes

- Teach through the current ConvictionSpread build rather than detached theory.
- Keep explanations concrete and define trading vocabulary when first introduced.
- Preserve a public GitHub trail after each meaningful completed task.
- Never ask the learner to paste API secrets into chat; credentials stay in local `.env`.
- Prefer one small lesson and one observable win at a time.
- Provide exact click paths and commands for setup tasks, with expected results.
